## Как скачать полный проект

В GitHub скачайте файл `hash_research.zip`, распакуйте его и откройте папку `hash_research`. В ней находятся все исходники, данные `results` и сведения о первоначальном запуске `provenance`. Отдельные файлы в корне репозитория предназначены также для чтения кода.

## Быстрый запуск на Mac

Откройте `Запуск_на_Mac.command` и выберите **1**. Будет создан новый HTML-отчёт: 234 проверки, изменение одного бита и известная коллизия MD5. Отчёт откроется в браузере; интернет не нужен. Проверено на установленном Python 3.14.6. Если macOS не открывает файл двойным щелчком, откройте Терминал, введите `bash `, перетащите файл `.command` в окно и нажмите Enter. В меню также есть хеширование текста/файла, полный эксперимент и просмотр сохранённых графиков. Новые запуски записываются в `local_runs`; исходные результаты остаются в `results`. Во время защиты используйте короткую демонстрацию; полный эксперимент выполните заранее.

## Запуск

Требуется Python 3.10 или новее. Ядро, проверки и SVG-графики используют только стандартную библиотеку. Исходный эксперимент выполнен на CPython 3.12.14; сведения находятся в results/environment.json. Сетевого доступа программа не требует.

Открыть терминал в этой папке:

```sh
python3 hash_study.py check
python3 hash_study.py hash --text "abc"
python3 hash_study.py collision
python3 hash_study.py run --out results_new
python3 plot_results.py results_new
```

На Windows обычно используется `py -3` вместо `python3`. Путь к файлу для режима хеширования передаётся через `--file "путь к файлу"`. Текст преобразуется в UTF-8 без добавления перевода строки. Файл читается порциями по 1 MiB.

Открыть `results_new/speed.svg` и `results_new/avalanche.svg` в браузере. Для короткой проверки работоспособности измерений:

```sh
python3 hash_study.py run --out smoke_new --repeats 4 --target 0.02 --trials 10
```

Этот сокращённый запуск не воспроизводит объём основного эксперимента и не должен подменять опубликованные результаты. Полный опыт занимает несколько минут, время зависит от компьютера. Непустая папка результатов не перезаписывается.

## Устройство программы

- `sha256_reference.py`: собственная учебная реализация SHA-256 по FIPS 180-4. Функция `rotr` выполняет циклический сдвиг; `sha256` дополняет вход, строит расписание из 64 слов и обрабатывает каждый 512-битный блок. Константы — стандартные, алгоритм не является новым. Эта реализация не включена в рейтинг скорости библиотек.
- `hash_study.py`: восемь опубликованных векторов, общий интерфейс `digest`, расстояние `distance`, проверки `check`, опубликованная коллизия `collision`, измерение `timed`, калибровка и повторения `performance`, опыт `avalanche`, сводные показатели `summarize`, сведения о среде `environment` и интерфейс `main`.
- `plot_results.py`: читает сводные CSV, преобразует координаты и записывает SVG без сторонних пакетов. По горизонтали в графике скорости используется логарифмическая шкала размера. Для лавинного опыта показаны средние, а не отдельные испытания и не доверительные интервалы.

Весь алгоритм вычисления, измеряемые операции и формулы описаны в разделе 3 курсовой. В `distance` каждое XOR выделяет различающиеся биты, `bit_count` считает их. В `avalanche` индекс делится на восемь для выбора байта, остаток определяет позицию бита. Маска XOR меняет ровно один бит. Явная проверка контролирует этот факт даже при запуске Python с оптимизацией.

## Основной эксперимент

Шесть библиотечных функций, десять размеров, 15 повторных серий. Перед ними — прогрев и калибровка до длительности серии не менее 0,1 секунды. Измеряется весь путь создания объекта и получения digest через общую Python-обёртку; генерация входа, запись CSV, чтение диска и графики не входят в таймер. Порядок задач перемешивается. Выбросы не удаляются.

Данные скорости: 900 серий. Лавинный опыт: 1000 пар на длину 16, 64 и 1024 байта; 3000 пар × 6 алгоритмов = 18000 измерений. Все алгоритмы получают одни и те же пары. Генератор `random.Random` используется для повторяемых тестов, не для секретных ключей. Сохранён точный корпус JSONL.

Числовые показатели в курсовой относятся к сохранённому запуску, а не к компьютеру студента, если он выполнит программу в другой среде. Модель процессора не удалось достоверно определить; вымышленное название не добавлялось. Частота, температура, фоновые процессы и энергорежим не контролировались.

## Файлы results

- `environment.json`: фактические ОС, Python, OpenSSL, архитектура, таймер и ограничения.
- `config.json`: seed, размеры, число серий и пар.
- `checks.json`: 234 пройденные проверки: 8 внешних векторов, 2 внешние проверки собственного SHA-256, 114 сравнений с библиотекой, 108 порционных проверок, 2 проверки расстояния.
- `performance_raw.csv`, `performance_summary.csv`: исходные времена, числа повторов, медианы и квартили inclusive.
- `avalanche_raw.csv`, `avalanche_summary.csv`: каждое испытание и сводные статистики; `sd_percent` — выборочное стандартное отклонение в процентных пунктах.
- `corpus.jsonl`: сообщения и позиции изменяемого бита.
- `data_sha256.json`: контрольные суммы входов бенчмарка.
- `source_sha256.json`: контрольные суммы двух вычислительных модулей на момент исходного запуска.
- `collision.json`: результаты проверки известной пары.
- `speed.svg`, `avalanche.svg`: воспроизводимые графики. PNG-копии подготовлены для вставки в документ.
- `verification.json`: дополнительная проверка сохранённых CSV и повторный расчёт лавинного опыта по сохранённому корпусу.

## Происхождение контрольных значений

1. MD5: RFC 1321, приложение A.5 — https://www.rfc-editor.org/rfc/rfc1321.html
2. SHA-1, SHA-256, SHA-512: RFC 6234, раздел 8.5 — https://www.rfc-editor.org/rfc/rfc6234.html
3. SHA3-256, пустое сообщение: NIST, SHA3-256_Msg0.pdf, последняя страница — https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Standards-and-Guidelines/documents/examples/SHA3-256_Msg0.pdf
4. SHA3-512, пустое сообщение: NIST, SHA3-512_Msg0.pdf, последние страницы — https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Standards-and-Guidelines/documents/examples/SHA3-512_Msg0.pdf
5. Пара MD5: Peter Selinger, MD5 Collision Demo — https://www.mscs.dal.ca/~selinger/md5collision/
6. Учебный SHA-256: FIPS 180-4, §§ 5–6 — https://csrc.nist.gov/pubs/fips/180-4/upd1/final

Ожидаемые внешние значения записаны в код явно, а не рассчитаны той же тестируемой функцией. Проверка известной пары не является собственным поиском коллизии. Совпадение статистик лавинного эффекта с ориентиром 50% не доказывает стойкость. Этот проект не является сертифицированным криптографическим средством.

## Исправления финального аудита

`--target` теперь отклоняет NaN и бесконечность. Проверка `verify_saved.py` работает и с `python3 -O`; шкала лавинного графика расширяется для коротких пробных запусков. Исходные числа курсовой не заменялись. `provenance/hash_study_original.py` — точная версия измерительного модуля первоначального запуска, а `source_changes.json` документирует изменение и обе контрольные суммы. Для воспроизведения исторического кода скопируйте этот файл в отдельную папку под именем `hash_study.py` вместе с `sha256_reference.py`. Основной запуск выполняйте исправленным `hash_study.py`.

Проверка сохранённых данных: `python3 verify_saved.py`. Дополнительные тесты: `python3 audit_tests.py`. Зависимости: только Python 3.10+ и стандартная библиотека; установка через pip не нужна.
